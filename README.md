## Tujuan
Mempelajari proses akuisisi dan manajemen data,
mulai dari pengumpulan hingga penyampaian hasil data.

## Struktur Folder
- data/raw: data mentah yang tidak ditimpa
- data/interim: data hasil pengolahan sementara
- data/processed: dataset final siap analisis
- notebooks: notebook praktikum
- src: script Python
- docs: dokumentasi dan metadata
- reports: laporan kualitas data

## Cara Menjalankan
1. Gunakan Python 3.11 atau versi lebih baru.
2. Instal library pandas, numpy, requests, dan beautifulsoup4.
3. Jalankan notebook di folder notebooks secara berurutan.
